One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, judged in private pairs by an AI judge.

## The entry

> Tip: your AI agent just fixed the same bug three times. The bug is fine. The agent is the bug. Go for a walk; it will still be broken when you get back.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single non-blank line of 1-200 characters with no em dash or control characters, then reading the file back to confirm it matches.
